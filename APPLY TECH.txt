## 🛠️ Step 1: Tambah Tabel `applications`
```sql
CREATE TABLE applications (
  id INT AUTO_INCREMENT PRIMARY KEY,
  career_id INT,
  name VARCHAR(150),
  email VARCHAR(150),
  message TEXT,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

---

## 📌 Controller (`Career.php`)
Tambahkan method `apply`:

```php
<?php
class Career extends CI_Controller {

    public function __construct() {
        parent::__construct();
        $this->load->model('Career_model');
        $this->load->model('Application_model');
    }

    public function apply($id) {
        $career = $this->Career_model->get_by_id($id);

        if ($this->input->post()) {
            $data = [
                'career_id' => $id,
                'name'      => $this->input->post('name'),
                'email'     => $this->input->post('email'),
                'message'   => $this->input->post('message')
            ];
            $this->Application_model->insert($data);
            $this->session->set_flashdata('success', 'Application submitted!');
            redirect('career');
        }

        $data['career'] = $career;
        $this->load->view('career_apply', $data);
    }
}
```

## 📌 Controller (`Career.php`)
Tambahkan konfigurasi upload di method `apply`:

```php
public function apply($id) {
    $career = $this->Career_model->get_by_id($id);

    if ($this->input->post()) {
        // Konfigurasi upload
        $config['upload_path']   = './uploads/applications/';
        $config['allowed_types'] = 'pdf|doc|docx';
        $config['max_size']      = 5120; // 5MB (dalam KB)
        $config['encrypt_name']  = TRUE;

        $this->load->library('upload', $config);

        $file_name = null;
        if (!empty($_FILES['cv_file']['name'])) {
            if ($this->upload->do_upload('cv_file')) {
                $file_data = $this->upload->data();
                $file_name = $file_data['file_name'];
            } else {
                $this->session->set_flashdata('error', $this->upload->display_errors());
                redirect('career/apply/'.$id);
            }
        }

        $data = [
            'career_id' => $id,
            'name'      => $this->input->post('name'),
            'email'     => $this->input->post('email'),
            'message'   => $this->input->post('message'),
            'cv_file'   => $file_name
        ];
        $this->Application_model->insert($data);

        $this->session->set_flashdata('success', 'Application submitted!');
        redirect('career');
    }

    $data['career'] = $career;
    $this->load->view('career_apply', $data);
}
```

Billy, error itu muncul karena di dalam **controller Career.php** kamu memanggil `$this->session->set_flashdata(...)`, tapi library **session belum diload**. Akibatnya properti `$this->session` bernilai `null`, sehingga muncul notice *Undefined property* dan fatal error *Call to a member function set_flashdata() on null*.

---

## 🔎 Penyebab
- CodeIgniter 3 tidak otomatis menyediakan `$this->session`.
- Supaya bisa dipakai, kamu harus **autoload** atau **load manual** library session.

---

## ✅ Solusi

### 1. Autoload Session (praktis untuk semua controller)
Edit file `application/config/autoload.php`:
```php
$autoload['libraries'] = array('database', 'session');
```
Dengan ini, session akan selalu tersedia di semua controller.

---

### 2. Load Manual di Controller
Tambahkan di constructor `Career.php`:

```php
<?php
defined('BASEPATH') OR exit('No direct script access allowed');

class Career extends CI_Controller {

    public function __construct() {
        parent::__construct();
        $this->load->library('session'); // wajib supaya $this->session ada
        $this->load->database();         // kalau pakai database
        $this->load->model('Career_model');
        $this->load->model('Application_model');
    }

    public function apply($id) {
        $career = $this->Career_model->get_by_id($id);

        if ($this->input->post()) {
            // proses upload + simpan data
            // ...
            $this->session->set_flashdata('success', 'Application submitted!');
            redirect('career');
        }

        $data['career'] = $career;
        $this->load->view('career_apply', $data);
    }
}
```

## 🎯 Analogi QC
Bayangkan `$this->session` itu seperti **mesin tambahan di pabrik**. Kalau belum dipasang (autoload/load manual), operator tetap mencoba menyalakan mesin → sistem bilang “mesin tidak ada” (undefined property). Jadi solusinya: **pastikan session diload dulu**.
